# 學員站

網址：<https://necva2018-lang.github.io/open-slide_a01/student/>

- 首頁只列出 `public.json` 裡的簡報；沒列進去的簡報不會被打包，學員站裡完全沒有它的內容。
- 講者備註不會打包進學員站。
- 點選簡報 → 全螢幕播放（16:9 等比縮放、黑邊補滿）。鍵盤 ← → 或手機左右滑動翻頁，按 Esc 回首頁。
- 右下角控制列：回首頁、上一頁／下一頁、頁碼、星星評價（顯示累積平均與人數）。
- 首頁每份簡報顯示頁數、瀏覽次數與 PDF 下載。

## 公開／下架簡報

編輯 `public.json` 的 `public`，例如公開 03：

```json
"public": ["01", "02", "03", "09"]
```

推上 `main` 後約 1 分鐘自動重新部署。

## 星星評價與瀏覽次數（Google 試算表）

資料存在你的 Google 試算表，免費。只需設定一次：

1. 開一份新的 Google 試算表，命名例如「學員站評價」。
2. 選單 **擴充功能 → Apps Script**，把 `apps-script.gs` 的內容全部貼上，取代原本的程式碼，儲存。
3. 上方函式選 `setup`，按 **執行**，依畫面完成授權（會出現「Google 尚未驗證這個應用程式」，點「進階」→「前往」即可，這是你自己的程式）。
4. 右上 **部署 → 新增部署作業**，類型選 **網頁應用程式**：
   - 執行身分：**我**
   - 具有存取權的使用者：**所有人**
5. 按部署，複製「網頁應用程式網址」（結尾是 `/exec`）。
6. 把網址貼到 `src/config.ts` 的 `RATING_ENDPOINT`，推上 `main`。

試算表會自動出現三張工作表：

| 工作表 | 內容 |
|---|---|
| 評分紀錄 | 每台裝置對每一頁一筆（匿名，重按會覆蓋舊的分數） |
| 頁面統計 | 每份簡報每一頁的評分人數與平均星數 |
| 瀏覽次數 | 每份簡報的累積開啟次數（同一個分頁視窗重複開只算一次） |

尚未設定網址前，星星只會記在學員自己的瀏覽器，不會累積。
之後如果修改了 `apps-script.gs`，要到 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」** 重新部署，網址不變。
