# 餐飲創業班簡報（open-slide）

為「職訓班・餐飲創業課程」製作的 10 份講座簡報，用 [open-slide](https://open-slide.dev) 以 React 撰寫，可在瀏覽器播放、輸出 PDF，並以 GitHub Pages 發布成靜態網站。

- 線上簡報：<https://necva2018-lang.github.io/open-slide_a01/>
- 場合：職訓班課程，每份約 45 分鐘，約 25 頁
- 聽眾：求職待業、正在接受專業技能培訓的學員，對主題多半沒接觸過

## 二、目錄結構

```
.
├── slides/            10 份簡報，每份一個資料夾（index.tsx＋講者備註 notes）
├── pdf/               10 份簡報的 PDF（逐頁截圖合併，翻牌卡只顯示正面）
├── tools/             產生簡報的工具：共用元件、色票、頁面原稿、截圖與 PDF 腳本
```

## 三、開發過程

1. **確認需求**：依序確認場合與時長、聽眾、帶走的東西、素材、數字、視覺方向，之後固定為標準答案，不再重複詢問。
2. **整理素材**：每份簡報讀完「簡報架構」「整理筆記」「影片逐字稿」三份資料，先整理成大綱草稿，經確認後才動手。
3. **版位公式**：封面 → 提問或便利貼 → 引子 → 這場不是什麼 → 目錄 → 各組（章節頁＋內容頁＋深色總結頁）→ 踩坑分享 → 工具 → 成果 → 課堂討論＋Q&A → 帶走三樣 → 一句話收尾。
4. **共用元件**：把版面、標題、卡片、表格、翻牌卡、章節進度條等寫成共用元件（`tools/kit-*.tsx.txt`），每份簡報只寫自己的頁面與備註，再由 `tools/build-deck.mjs` 組合。
5. **每份不同配色**：10 組低彩度的暖色系或穩重色票（`tools/palettes.json`），文字、強調色、警示色與底色的對比度都 ≥ 4.5:1。
6. **驗收**：用瀏覽器自動化逐頁截圖（1920×1080），逐張目視；再縮小 50% 模擬視訊會議畫質；程式檢查文字是否超出版面；實測翻牌卡在播放模式的點擊；檢查沒有講者姓名與不當用語。
7. **評論迭代**：用 open-slide 內建的 Inspector 留言，初修整份順完一次套用，細修再逐頁調整。
8. **輸出**：用截圖合併成 PDF（不用瀏覽器列印，避免跑版），並用 GitHub Pages 發布。

完整規則見 [docs/簡報製作規則.md](docs/簡報製作規則.md)；製作紀錄與驗收結果見 [docs/製作報告_01-02.md](docs/製作報告_01-02.md)、[docs/製作報告_04-10.md](docs/製作報告_04-10.md)。

## 四、本機使用

需要 Node.js 18 以上。

```bash
npm ci
npm run dev        # 開發伺服器，網址 http://localhost:5173
npm run build      # 輸出靜態網站到 dist/
```

- 在簡報頁按 **F** 進入播放模式；翻牌卡等互動元素在編輯畫面點不動，要在播放模式才會動。
- 在編輯畫面按 **Inspect** 點選元素並在 **Comment** 留言，留言會存進程式碼。

### 產生簡報的工具（選用）

`tools/` 需要自己的相依套件（`cd tools && npm ci`），並先啟動開發伺服器。

```bash
bash tools/run-deck.sh <id> <色票名稱> <標題> <章節json> <頁面檔> <頁數> <輸出資料夾>
node tools/mkpdf.mjs <截圖資料夾> <頁數> <輸出pdf> <標題>
```

截圖腳本預設使用 `C:/Program Files/Google/Chrome/Application/chrome.exe`，在其他系統請修改 `executablePath`。

## 五、GitHub Pages 部署

推送到 `main` 後，`.github/workflows/pages.yml` 會自動建置並發布。第一次使用時，請到 repository 的 **Settings → Pages**，把 **Source** 設為 **GitHub Actions**。

- 部署時以環境變數 `BASE_PATH=/open-slide_a01/` 建置，網站路徑才會正確。
- GitHub Pages 沒有伺服器端轉址，所以建置後把 `index.html` 複製為 `404.html`，讓直接開啟 `/s/<id>` 的連結也能進入簡報。
- 靜態網站上的 Inspector 留言與設計面板不可用（它們需要開發伺服器），只能播放與瀏覽。

## 六、已知限制

- PDF 是圖片，不能選取文字；翻牌卡只顯示正面，看不到背面答案。
- 字型從 Google Fonts 載入，離線或網路不好時會退回系統字型，版面略有差異。現場請另存離線備份。
- 簡報中的營收、成本、人數等數字，皆為受訪者或業界創業者的個人經驗，簡報上已標示「不是統計」，並非統計數據。
- 訪談類簡報（09、10）受訪者全部匿名。
- 原始影片逐字稿與整理筆記不在本專案內。

## 七、內容來源與標示

簡報內容整理自公開的餐飲創業影片，僅摘要重點並以自己的話重新整理，不含逐字稿原文。簡報上的「延伸建議」標籤，表示該段是整理者依內容推導的建議，不是影片原話。
